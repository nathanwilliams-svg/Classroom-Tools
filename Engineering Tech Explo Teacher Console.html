      How this works
      • Click any step on the left to jump to it. The check box marks it done.
      • Space starts or pauses the timer. ← → move between steps. P projects the student view.
      • Change any timer with the −/+ buttons, or type an exact time in Set time. Your change is remembered for that step.
      • + and − zoom the console. In the class view they zoom just the projected text.
      • N Our Norms · A Ask 3 · L Links · C Class & Students · G Lottery Picker · J Jigsaw Groups (Day 2) · T today’s learning target.
      • In the class view you can keep teaching: Steps jumps to any step, and Norms, Ask 3, Target, and Lottery stay on screen. Private tools (class list, links, notes) open only after you leave the class view.
      • N in the class view lets you type norms right on the board. R makes new random pairs from your class list — they appear under Random pairs, or on the board if you’re projecting.
      • Slide numbers match the 69-slide PowerPoint, Unit1_Smartboard_Presentation.pptx. Slides 1 and 11–13 were removed from this console.
      • Progress, norms, class lists, notes, and settings are saved in this browser only. Use Backup to keep a copy.
